QUICK START (3 Steps)
--------------------
1. Edit Configuration:
   - Open dub_automation.py
   - Update FTP_HOST, FTP_USER, FTP_PASS (lines 17-20)
   - Update directory paths if needed (lines 10-14)

2. Run Startup Script:
   chmod +x start.sh
   ./start.sh

3. Open Browser:
   http://localhost:7020

WORKFLOW SUMMARY
---------------
1. Upload DUB file (drag & drop)
2. System searches FTP automatically
3. Review and approve matches
4. Monitor download queue
5. Files validated and renamed
6. Files moved to watch folder
7. Generate report
